# Vercel deployment

This is a plain static website. Deploy the **entire project folder**, not only `index.html`.

The `assets/` folder is required and contains the SOCC logo, speaker photos, and gallery photos.

## GitHub
1. Put `index.html`, `styles.css`, `script.js`, `vercel.json`, and the complete `assets/` folder in the repository.
2. Commit and push all files.
3. In Vercel, import that repository.
4. Leave the framework as **Other** / static site and keep the project root at the repository root.

If you update a photo, replace the file inside `assets/` and commit/push it as well.
